
# Commandدو

Welcome to Commandدو! This app is designed to make it easy for office employees to order food from local restaurants through their office boys and have it delivered to their workplace.

## Getting Started

To get started with the app, you will need to have [React Native](https://reactnative.dev/docs/environment-setup/) installed on your development machine.

Once you have React Native set up, clone this repository and install the dependencies:

```bash
git clone https://github.com/eSpark-Consultants/Command-do.git
cd Command-do
npm install
```

Then, you can run the app in your emulator or on your device with:

```bash
npm run android   //for Android devices
```

## Features

### Feature List

- Browse a list of lunch Items avalaible near your office 
- Place an order and pay for it
- Track the status of your order and get notified when it has been delivered
- View Past orders and Track all order History
- Save your favorite items for quick ordering in the future
